# The B.A.S.I.L.I.S.K. Virus

A sibling build to the NIMROD Virus — a "Double Elite" machine intelligence
(42 HP, flying) with the same crowd-control-plus-packmaster chassis, but it
fields manufactured **Drones** instead of infected Huntsmen, and its action
tempo shifts when Bloodied (acts on counts 6/4 fresh; 7/5/3 once Bloodied —
it gets *faster* as it takes damage).

Use it where NIMROD's body-horror infection angle doesn't fit but you still
want the raid-boss structure: labs, networks, hijacked facilities. The two
bosses are deliberately interchangeable — swapping one for the other
re-skins a prepped fight in seconds.

Statblocks: `stats.json` (level 4).
